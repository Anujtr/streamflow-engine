# StreamFlow Engine Demo Testing Suite

This directory contains comprehensive testing tools for validating the StreamFlow Engine demo application.

## 📋 Testing Components

### 1. **Integration Test Suite** (`integration_test.py`)
Python-based comprehensive integration testing covering all demo components.

**Features:**
- Service health checks
- REST API endpoint validation
- WebSocket connection testing
- Traffic pattern functionality
- End-to-end data flow validation
- Fraud detection verification

**Usage:**
```bash
# Ensure all services are running
docker-compose up -d

# Run integration tests
python3 integration_test.py

# Show help
python3 integration_test.py --help
```

**Requirements:**
- Python 3.8+
- `requests` library
- `websocket-client` library (installed automatically)

### 2. **Load Testing** (`load_test.go`)
Go-based performance and load testing for the demo services.

**Features:**
- Service availability testing
- Concurrent request load testing
- Traffic pattern performance validation
- Latency and throughput measurement
- Performance assessment with benchmarks

**Usage:**
```bash
# Build the load tester
go build load_test.go

# Run load tests
./load_test

# Or run directly
go run load_test.go
```

**Configuration:**
- Default: 50 req/sec for 2 minutes with 10 concurrent clients
- Tests all REST endpoints across simulator and pipelines services
- Includes traffic pattern stress testing

### 3. **Demo Validation Script** (`validate_demo.sh`)
Bash script for quick validation of demo functionality.

**Features:**
- Automated service health checking
- API endpoint validation
- WebSocket connectivity testing
- Traffic pattern functionality verification
- End-to-end data flow validation
- Comprehensive reporting

**Usage:**
```bash
# Make executable (if needed)
chmod +x validate_demo.sh

# Run validation
./validate_demo.sh

# Show help
./validate_demo.sh --help
```

**Dependencies:**
- `curl` command
- `python3` with basic libraries
- `websocket-client` Python package (installed automatically)

## 🔧 Troubleshooting

### Common Issues

**Services Not Starting:**
```bash
# Check service status
docker-compose ps

# View logs
docker-compose logs [service-name]

# Restart specific service
docker-compose restart [service-name]
```

**Connection Failures:**
```bash
# Check port availability
netstat -tulpn | grep :8000
netstat -tulpn | grep :8081

# Verify service URLs
curl http://localhost:8000/health
curl http://localhost:8081/health
```

**Test Dependencies Missing:**
```bash
# Install Python dependencies
pip3 install requests websocket-client

# Verify curl availability
which curl

# Install Go if needed
# https://golang.org/doc/install
```

**WebSocket Connection Issues:**
- Ensure firewall allows local connections
- Check that services are fully initialized before testing
- Verify no proxy settings interfering with WebSocket connections
